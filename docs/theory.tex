\section{Постановка задачи}

\subsection{Прямая задача}
Рассмотрим задачу распространения тепла в полуограниченном стержне при наличии внутренних источников, плотность мощности которых описывается функцией $f(x, t)$. Начальное распределение температуры стержня задано и равно $u_0(x)$, а на границе $x = 0$ определен тепловой поток $\gamma(t)$. 
Математическая формулировка задачи имеет следующий вид:
\begin{align*}
        &u_t(x, t)= a^2u_{xx}(x, t) + f(x, t), \ \ x > 0, \ \ t > 0, \\
        &u_x(0, t) = \gamma(t), \ \ t > 0,\\
        &u(x, 0) = u_0(x), \ \ x >  0.
\end{align*}
\subsection{Обратная задача}

Рассмотрим теперь обратную задачу определения источника. Слагаемое $f(x,t) \equiv f(x)$ считается неизвестным. Для нахождения источника фиксируется дополнительная информация, а именно - значение функции $u_t(x, t)$ на правой границе отрезка времени $[0, T]$. Постановка задачи имеет вид.

\begin{align*}
        &u_t(x, t)= a^2u_{xx}(x, t) + f(x), \ \ x > 0, \ \ t > 0, \\
        &u_x(0, t) = \gamma(t), \ \ t > 0,\\
        &u(x, 0) = u_0(x), \ \ x > 0,\\
        &u_t(x, T) = u_T(x), \ \ x > 0.
\end{align*}

Функция $u_T(x)$ задана. Таким образом, зная $\gamma(t), u_0(x), u_T(x)$, требуется восстановить $u(x, t)$ и $f(x)$.
\section{Исследование задачи}
В силу линейности исходной задачи путём подстановок ее можно редуцировать к более простой.
\begin{align*}
        &u_t(x, t)= a^2u_{xx}(x, t) + f(x), \ \ x  > 0, \ \ t > 0, \\
        &u_x(0, t) = 0, \ \ t > 0,\\
        &u(x, 0) = 0, \ \ x > 0,\\
        &u_t(x, T) = \varphi(x), \ \ x > 0.
\end{align*}

\subsection{Разрешающие формулы}
Пользуясь косинус преобразованием Фурье, можно найти решение:
$$u(x, t) = \int_{0}^{t}\frac{1}{\sqrt{4\pi a^2 s}}\int_{0}^{+\infty}\bigg(e^{-\frac{(x - y)^2}{4a^2s}} + e^{-\frac{(x + y)^2}{4a^2s}}\bigg)f(y) \, dy \, ds.$$
Дифференцируя по переменной $t$, получим
$$u_t(x, t) = \frac{1}{\sqrt{4\pi a^2 t}}\int_{0}^{+\infty}\bigg(e^{-\frac{(x - y)^2}{4a^2t}} + e^{-\frac{(x + y)^2}{4a^2t}}\bigg)f(y) \, dy$$
тогда
$$\varphi(x) = u_t(x, T) = \frac{1}{\sqrt{4\pi a^2 T}}\int_{0}^{+\infty}\bigg(e^{-\frac{(x - y)^2}{4a^2T}} + e^{-\frac{(x + y)^2}{4a^2T}}\bigg)f(y) \, dy.$$
$$\varphi(x) = A_T(f)(x).$$
Итого, для восстановления $f(x)$ требуется решить интегральное уравнение Фредгольма первого рода.



\subsection{Эквивалентность уравнению теплопроводности с обратным направлением времени}
Продолжим функцию $f(x)$ четным образом на всю прямую $\mathbb{R}$, тогда 
\begin{align*}
        u_t(x, t) &= \frac{1}{\sqrt{4\pi a^2 t}}\int_{0}^{+\infty}\bigg(e^{-\frac{(x - y)^2}{4a^2t}} + e^{-\frac{(x + y)^2}{4a^2t}}\bigg)f(y) \, dy = \\
                  &= \frac{1}{\sqrt{4\pi a^2 t}}\int_{-\infty}^{+\infty}e^{-\frac{(x - y)^2}{4a^2t}}f(y) \, dy
\end{align*}
Полученная формула, как известно, является решением уравнения теплопроводности с обратным направлением времени
\begin{align*}
        &v_t(x, t)= a^2v_{xx}(x, t), \ \ x  \in \mathbb{R}, \ \ t > 0, \\
        &v(-x, t) = v(x, t), \ \ x  \in \mathbb{R}, \ \  t > 0,\\
        &v(x, 0) = f(x), \ \ x  \in \mathbb{R}, 
\end{align*}
где $v(x, t) = u_t(x, t), \ \ x > 0$.
Тогда эквивалентная исходной обратная задача будет иметь вид
\begin{align*}
        &v_t(x, t)= a^2v_{xx}(x, t), \ \ x  \in \mathbb{R}, \ \ t > 0, \\
        &v(-x, t) = v(x, t), \ \ x  \in \mathbb{R}, \ \  t > 0,\\
        &v(x, T) = \varphi(x), \ \ x  \in \mathbb{R}, 
\end{align*}
в которой нужно восстановить $u(x, 0) = f(x)$ по известному $\varphi(x)$. 
Таким образом решение данной задачи при $x > 0$ будет решением исходной.
Далее будем работать с эквивалентной задачей.

\section{Методы решения операторного уравнения}
Требуется решить интегральное уравнение Фредгольма 1-го рода:
\begin{equation}
\varphi(x) = v(x, T) = \frac{1}{\sqrt{4\pi a^2 T}}\int_{-\infty}^{+\infty}e^{-\frac{(x - y)^2}{4a^2T}}f(y) \, dy.
\end{equation}
$$\varphi(x) = A_T(f)(x).$$

Рассмотрим два подхода: классический через градиентные методы и нейросетевой через глубокое обучение.
\subsection{Градиентный метод}
В этом подходе решение ищется как минимум функционала
\begin{equation*}
J[v] = \|A_T v - \varphi\|^2_{L_2},
\end{equation*}
а сам функционал минимизируется методом градиентного спуска.

Итерационный процесс метода градиентного спуска строится по правилу:
\begin{align*}
    &\widetilde{v}^{k} = v^{k-1} - \alpha \nabla J[v^{k-1}], \, \, \ \ \ k = 1,2,...,N, \\
    &v^k = P(\widetilde{v}^{k}).
\end{align*}
где $v^0$ - некоторое начальное приближение, $N$ - количество итераций, $\nabla J[v]$ - производная по Фреше функционала, $\alpha$ - шаг спуска, а $P$ - оператор проекции на множество решений.
Результатом метода считается $v^N$.

\subsection{Глубокое обучение}
В качестве эффективной альтернативы классическим подходам рассматривается применение методов глубокого обучения.
В частности, нейрооператора Фурье (Fourier Neural Operators, FNO) — передовая архитектура машинного обучения, предназначенная для аппроксимации операторов между бесконечномерными функциональными пространствами.

\section{Построение модели FNO}
\subsection{Генерация обучающей выборки}

Для простоты обучим модель приближать решение в случае, когда в исходном уравнении параметр $a = 1$.

Обучающей выборкой служит набор пар вида $([\varphi(x), T], f(x))$, элементы которого связаны через уравнение (1).
Формально, обученная модель принимает на вход пару $[\varphi(x), T]$ и делает прогноз вида $f(x) = FNO([\varphi(x), T])$.

Для генерации обучающих данных используется два типа функций источников:

1) Гауссианы вида $f(x) = A e^{w(x - x_0)^2}$, где параметры выбираются из равномерного распределения: $A \in [1, \  5], \ w \in [0.1, \ 1], \ x_0 \in [3, \ 7]$.

2) Сумма гауссиан: $f(x) = A_1 e^{w_1(x - x_{01})^2} + A_2 e^{w_2(x - x_{02})^2}$, параметры выбираются аналогичным образом.

Тип функции выбирается случайным образом с равным шансом. Затем выбирается $T$ из равномерного распределения на отрезке $T \in [0.1, \ 2]$. 

Из полученных данных составляется оператор $A_T$ из уравнения (1) и затем вычисляется $f(x) = A_T(\varphi)(x)$.
Всего генерируется 5000 элементов для обучающей выборки.

\section{Результаты расчетов}
Для каждого эксперимента выбирается $f(x), \ x > 0$ и некоторое $T$ по ним вычисляется $\varphi(x) = A_T(f)(x)$ и затем составляется обратная задача по восстановлению $f(x)$.
В каждом примере будет приведен результат работы оператора FNO и классического градиентного метода. В качестве примеров выбраны данные не из обучающей выборки, но класс функций все тот же.
Постановка задачи
\begin{align*}
        &u_t(x, t)= u_{xx}(x, t) + f(x), \ \ x  > 0, \ \ t > 0, \\
        &u_x(0, t) = 0, \ \ t > 0,\\
        &u(x, 0) = 0, \ \ x > 0,\\
        &u_t(x, T) = \varphi(x), \ \ x > 0,
\end{align*}
