# Введение
В настоящей работе исследуется одномерная начально-краевая задача теплопроводности на полуоси с граничным условием второго рода. 

Основные этапы исследования:
* С помощью интегрального **косинус-преобразования Фурье** получены разрешающие соотношения для прямой задачи.
* Сформировано **операторное уравнение** для решения обратной задачи.

В репозитории реализованы и сравниваются две подхода к решению обратной задачи:
1. **Классический подход** — сопряжен с поиском минимума функционала оптимизационными градиентными методами.
2. **Обучаемый подход** — базируется на применении нейронных операторов Фурье (Fourier Neural Operators, FNO).
